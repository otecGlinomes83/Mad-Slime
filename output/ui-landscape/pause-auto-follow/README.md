# Исправление переключения меню паузы

В Prefab Mode режим по умолчанию «Размер области → Из Game View (автоматически)» следует за Game View и применяет соответствующий профиль при открытии и смене ориентации. Работает при выбранном дочернем объекте. Смена разрешения в той же ориентации сохраняет ручные правки. Логические размеры учитывают Canvas Scaler Expand.

Основная панель паузы: Portrait 960×960; Landscape 1360×900. Ранее оба профиля были 960×960.

Область после сохранения восстанавливается в самом prefabSaved, без переноса на следующий кадр. Проверены события сохранения и следующее обновление редактора; покадровая запись нативного окна не выполнялась.

Проверки Prefab Mode, сохранения/повторного открытия и Play Mode в обеих ориентациях прошли. Runtime: оба контекста с кнопкой домой/сброса, размеры и границы панели, слайдеры, ошибок нет. Отчёты и снимки рядом. Файлы основного проекта совпадают с проверенной копией.
