# Подложка цены и выравнивание бара роста

В Menu/SkinsWindow/BuySkinButton/Price компонент Image использовал Pixels Per Unit Multiplier=1, а баланс — 2. При одинаковой геометрии исходных спрайтов это удваивало радиус углов цены. Теперь у обоих значение 2, Image Type=Sliced.

В Game/GrowthBarContent/Background Anchored Position Y=6 вместо 0. Сдвиг учитывает нижнюю тень внешнего спрайта и центрирует дорожку, заполнение и надпись по видимой рамке.

Play Mode Unity 2022.3.62f2: магазин проверен при 1080×1920 и 1920×1080, оба Image имеют multiplier=2. Игровой UI проверен при 1920×1080, 2560×1080, 1080×1920 и 960×540. Проверки геометрии прошли, подробности в price-validation.txt и game-validation.txt. Служебные скрипты и тестовые сохранения остались в отдельной копии проекта.
