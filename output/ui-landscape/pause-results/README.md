# Пауза, результаты и покупка скина

- Menu.unity: цена покупки закреплена в нижней части кнопки (anchor Y=0.3), заголовок — в верхней. В горизонтали высота кнопки 180, нижний отступ сохранён. Цена целиком внутри зелёной плашки, без перекрытия заголовка.
- PauseMenu.prefab: окно 960×960 вместо 840×820. Язык ниже аудио, кнопка домой ниже языка. Увеличены язык, домой, сброс и закрытие. MusicSlider повторяет геометрию SFXSlider: полоса 509.416×100, ручка 100×100; иконки обоих каналов 128×128. Ссылки на аудиоканалы сохранены.
- WinMenu/FailMenu.prefab: все три кнопки каждого окна увеличены ровно вдвое — 160×114 → 320×228, 280×114 → 560×228. Горизонталь: один ряд, окно 1360×900. Вертикаль: основная кнопка выше, две вторичные ниже, окно 1000×1240. Иконки кнопок увеличены. У спасения текст и стрелка разведены, подпись помещается.
- FailMenu: светло-красный фон, тёмно-красный заголовок, коралловые кнопки и плашка награды.

Play Mode Unity 2022.3.62f2, отдельная копия: магазин, настройки и пауза с кнопкой домой в 1920×1080 и 1080×1920; оба результата также при 960×540. Проверены границы окон/кнопок, отсутствие наложений, переполнение текста, одинаковые слайдеры и порядок язык/домой. Английский вариант победы также проверен. Runtime errors=0. Изменённые строки не добавляют пробелов на концах; существующее форматирование Unity YAML сохранено.
