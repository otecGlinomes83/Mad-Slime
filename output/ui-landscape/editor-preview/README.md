# Проверка предпросмотра главного меню

Проверена копия текущей Menu.unity в Unity 2022.3.62f2. Основная сцена не изменялась. Custom Inspector совпадает с проверенной копией побайтово.

Вызваны обработчики Preview/Capture настоящего ResponsiveCanvasLayoutEditor на MainMenuWindow: вне Play Mode, Portrait и Landscape, ручная правка позиции/размера DailyButton, запись профиля, переключение обратно, сохранение/повторное открытие сцены, запуск игры и повороты в обе стороны. Все проверки PASS (validation.txt). Кнопки инспектора физически мышью не нажимались; заявленный пользователем случай полного отсутствия реакции не воспроизведён.

Скриншоты edit-portrait.png и edit-landscape.png получены из Game View вне Play Mode. edit-captured-portrait.png содержит тестовую ручную правку; она не переносилась в основную сцену.

## Как править

1. Остановить Play Mode, включить и выбрать MainMenuWindow.
2. В Game View выбрать 9:16 для вертикали или 16:9 для горизонтали.
3. На Responsive Canvas Layout нажать «Показать вертикаль/горизонталь». Проверить сообщение о применении и количество объектов (у главного меню 7).
4. Поправить Rect Transform объектов, включённых в Elements.
5. Нажать «Записать в Portrait/Landscape», затем Ctrl+S. Перед переключением профиля обязательно записать ручные правки.

Кнопка «Показать» применяет сохранённые координаты и не меняет разрешение Game View. Профиль хранит только Target из Elements: якоря, pivot, позицию, размер и равномерный масштаб. Текст, спрайты и внутренние элементы кнопок в эти снимки не входят.

В инспектор добавлены имя объекта, количество целей, текущий размер Game View, последний выбранный профиль, сообщения о применении/записи и предупреждения о пустом Elements, неактивном окне и несовпадении ориентации. После операций принудительно обновляются окна редактора, включая Game View.
