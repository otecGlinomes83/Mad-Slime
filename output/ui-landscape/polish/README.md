# Денежные иконки, ракурсы и настройки

- По оригинальным изображениям из GUI Kit Casual Game заново нарисованы шесть иллюстраций: отдельная монета, несколько монет, стопка, горсть, мешок, сейф. Новые PNG с прозрачным фоном: 1280×1280. В рулетке назначены пять разных денежных наград по существующим порогам 150/300/1000/3000; баланс использует отдельную монету. Старые изображения пакета сохранены.
- Все 34 иконки скинов заново отрендерены исходным методом SkinItemFactory, с прежней камерой под 30° и без дополнительного поворота модели на 45°. Разрешение повышено до 512×512. Изображения общие для каталога, загрузки и наград. Живое 3D-превью сохранило ранее существовавшее вращение.
- Оба заголовка колонок используют один PerkSeporator.prefab, размер 36, Bold и прописные буквы. Раньше слева был другой prefab, обычное начертание и строчные буквы.
- ShopItemView снова применяет полный цвет из SkinRarityTable, без ослабления до 14%.
- В награде включён существующий Fx_Rotate с двумя ParticleSystem и UIParticleSystem. Масштаб подогнан к новой панели; работа при паузе использует независящее от Time.timeScale время.
- Слайдеры получили понятную настройку размеров через Rect Transform вложенного Slider. Подробная инструкция: [SLIDERS.md](SLIDERS.md).

## Проверка

Play Mode Unity 2022.3.62f2, отдельная копия проекта. `validation.txt`: ошибок 0. Дополнительно к предыдущим проверкам проверены одинаковые параметры заголовков, полные цвета редкости, пять различных денежных иконок, назначение мешка и сейфа, активные испускающие частицы с UI-рендерерами, изменение слайдера на 560×64 и соответствующий размер ручки. Проверены оба языка и портрет/горизонталь, попапы, покупки, сетка магазина. `loading-validation.txt`: экран загрузки использует восстановленную иконку Car 512px.

Скриншоты находятся в `screens/`. Тестовые деньги, сохранения и служебные скрипты не перенесены в основной проект. Отдельная сборка плеера/WebGL не запускалась.

## Источники иллюстраций

Встроенный ImageGen, transparent_background=true. Референсы композиции: `btn_icon_gold.png` и `shop_img_gold_0..4.png` из исходного GUI Kit Casual Game. Референс стиля: новая иконка Speed. Постановки и пути результатов сохранены в `money-artwork.json`. Новые Coin/Coins — растровые иллюстрации; устаревшие векторные черновики Coin.svg и Coins.svg удалены из Unified/Sources.
