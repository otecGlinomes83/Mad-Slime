# Как менять размеры слайдеров

Открой в Unity **Assets → MadSlime → Resources → Prefabs → UI → Menu → PauseMenu.prefab**, двойным щелчком, вне Play Mode. Этот prefab используется в главном меню и во время игры.

В иерархии prefab выбери один из объектов:

```text
PauseMenu
└─ Menu
   ├─ SFXSlider
   │  └─ Slider       ← громкость эффектов
   └─ MusicSlider
      └─ Slider       ← громкость музыки
```

После последней правки паузы оба слайдера повторяют настроенную геометрию SFX: **509.416×100**. Вложенный Slider растянут по высоте строки.

Для длины выбери вложенный **Slider → Rect Transform → Width**. Для толщины выбери его родителя **SFXSlider** или **MusicSlider → Rect Transform → Height** (сейчас 100); полоса и круглая ручка следуют высоте строки. При растянутых вертикальных якорях у вложенного Slider вместо Height видны Top/Bottom — оставь их равными 0.

Ниже — исходный пример с фиксированной высотой до этой правки:

| Поле | Что меняет |
|---|---|
| Width | Длину полосы |
| Height | Высоту контрола; толщина полосы и диаметр ручки следуют ей |
| Pos X / Pos Y | Положение внутри строки |

Пример: **Width = 560, Height = 64** — более длинная и толстая полоса. Исходный размер — **492×42**. Скриншот примера ниже: верхний слайдер изменён, нижний оставлен исходным.

![Пример Width 560 Height 64](screens/settings-resized-slider.png)

Теперь Background и Fill Area используют относительные якоря по высоте. Ручка сохраняет круглую форму через Aspect Ratio Fitter → Height Controls Width. Растягиваемые фоны используют Sliced. При обычном изменении размеров править дочерние Background/Fill/Handle отдельно не требуется.

**SFXSlider/MusicSlider** уровнем выше — строки с иконкой и контролом. Для изменения длины самой полосы выбирай именно вложенный **Slider**. Чтобы дать ему больше места возле иконки или сместить строку целиком, меняй Rect Transform строки.

Сохрани prefab. Его новые размеры будут применяться при следующих открытиях настроек. Правки экземпляра в Play Mode используются только для текущего запуска.
