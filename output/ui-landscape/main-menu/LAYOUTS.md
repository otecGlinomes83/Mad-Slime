# Как устроены и редактируются две раскладки

Открой сцену `Assets/MadSlime/Scenes/Menu.unity`. В иерархии включи и выбери `MainMenuWindow`. На нём находится `ResponsiveCanvasLayout`; все 7 целей главного меню уже назначены (заголовок и 6 кнопок). Вручную заполнять Elements для меню не нужно. `Background` — первый дочерний объект `MainMenuWindow`, растянутый якорями на всё окно. Отдельного `MenuBackground`, Canvas и управления фоном в MenuNavigation больше нет; фон следует активности главного окна.

Один набор объектов используется в обеих ориентациях. В списке Elements у каждого Target хранятся два набора Rect Transform: Portrait и Landscape. Они содержат якоря, pivot, позицию, размер и масштаб. Для экранов, где это требуется, также можно назначить разного родителя. Общие спрайты, текст и действия кнопок остаются на тех же объектах.

В игре компонент выбирает Landscape при Screen.width > Screen.height, иначе Portrait, применяет раскладку при включении и изменении размеров окна. Canvas Scaler использует Expand и опорный размер 1920×1080 или 1080×1920.

## Порядок настройки

Настройка выполняется вне Play Mode. В инспекторе оставлены только две кнопки записи; кнопки предпросмотра удалены по запросу пользователя.

1. В Game View выбери нужный формат: например, 1080×1920 для Portrait или 1920×1080 для Landscape.
2. Настрой Rect Transform нужных объектов. Изменение формата Game View само не применяет сохранённый профиль в Edit Mode.
3. Выбери MainMenuWindow и нажми **Записать в Portrait** или **Записать в Landscape**, затем сохрани сцену (Ctrl+S).
4. Для второй ориентации поменяй формат Game View, расставь объекты и запиши второй профиль.

Запись сохраняет текущие якоря, pivot, позицию, размер и равномерный масштаб только для объектов из Elements. Она не двигает объекты и не меняет разрешение Game View. Вложенные иконки, надписи, цвета и спрайты в профиль не записываются. Поля Portrait/Landscape в Elements также доступны для непосредственного редактирования. В Play Mode применяется профиль по текущим размерам Game View; кнопки записи там недоступны, чтобы не сохранять временные игровые значения.

## Общий сепаратор

Единственный исходный prefab: `Assets/MadSlime/Resources/Prefabs/UI/UISeparator.prefab`. Удалён старый неиспользуемый Skins/PerkSeparator; активный PerkSeporator переименован с сохранением GUID, ссылки сохранены. Заголовки навыков и одноразовых покупок, а также заголовки редкостей магазина используют этот prefab. Общие шрифт, размер 36, жирность, геометрия и фон задаются в нём.

В магазине текст/цвет редкости задаёт SkinRarityGroupView; общий LocalizedText там отключён, чтобы не заменять редкость текстом одноразовых покупок. Для расположения над сеткой у экземпляра separator включён LayoutElement.IgnoreLayout. Это настройка контейнера, оформление наследуется из общего prefab.

Проверены тексты, отсутствие наложений/выхода за экран, общие сепараторы прокачки и четырёх редкостей, смена языка в магазине. Runtime errors=0.

После удаления предпросмотра проверены оба обработчика записи в настоящем custom Inspector: позиция и размер сохраняются в нужный профиль без перемещения объектов, оба профиля сохраняются после повторного открытия сцены. Результат: output/ui-landscape/editor-preview/capture-only.txt.
