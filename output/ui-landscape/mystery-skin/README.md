# Иконка случайного скина

MysterySkin.png: простая плоская бирюзовая футболка на чёрной вешалке с крупным вопросительным знаком. Встроенный ImageGen, размер 1254×1254, толстая тёмная обводка, без складок, швов, бликов и мелких деталей. Unity Sprite, Bilinear, без mipmaps, без сжатия по умолчанию, max size 2048.

RouletteView.prefab → RouletteView → Secret Icon теперь ссылается на MysterySkin вместо Gift. Код не менялся.

Проверено в Play Mode при 1080×1920 и 1920×1080: новый спрайт импортирован в полном размере, назначен активному сектору рулетки, preserveAspect=true. Скриншоты рядом.
