# Организация скриптов по системам — Implementation Plan

> **For agentic workers:** Execute inline with the executing-plans workflow; no delegated tasks are needed. Steps use checkbox syntax.

**Goal:** Разложить собственные скрипты по системам и подсистемам, отдельно хранить классы ScriptableObject.

**Architecture:** `Assets/MadSlime/Scripts/<System>/<Subsystem>` содержит связанные классы, интерфейсы, UI, адаптеры и редакторские инструменты. `Scripts/ScriptableObjects/<System>` содержит классы SO. Существующее распределение типов между сборками сохраняется через `.asmref`; определения сборок находятся в `Scripts/Assemblies`.

**Tech Stack:** Unity 2022.3.62f2, C#, asmdef/asmref, Python для проверяемого переноса файлов.

**Spec:** Требования пользователя в чате и `Wiki/Ревью/Системы и скрипты для рефакторинга.md`.

## Global Constraints

- Перенести все 170 собственных C#-скриптов вместе с исходными `.meta`.
- Сохранить GUID, namespace, поведение и исходную принадлежность каждого файла к сборке.
- ScriptableObject хранить отдельно, обычные enum/serializable-классы — в соответствующей системе.
- Сторонние пакеты, сцены, префабы и существующие экземпляры SO не изменять.
- Перенести исходник генерируемого ввода рядом с его C#-обёрткой.

## Review Focus

- Ссылки сцен и префабов сохраняются благодаря неизменным GUID скриптов.
- Адаптеры YG остаются в Assembly-CSharp, редакторские инструменты — в Assembly-CSharp-Editor.
- UI, Gameplay и Core сохраняют прежнее распределение файлов без новых циклических зависимостей.
- Регенерация Input Actions создаёт обёртку в новой папке ввода.
- Документация содержит актуальные ссылки на перенесённые файлы.
