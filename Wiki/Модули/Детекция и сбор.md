# Детекция и сбор

**Слой:** Gameplay · **Код:** `Assets/MadSlime/Scripts/Detection/GenericOverlapDetector.cs`, `Collectables/` (ItemDetector, AttractableDetector, ItemAttractor, Collector, Absorber, ItemGhostToggler)

Конвейер «предмет у рта → полёт в пасть → событие сбора».

## Конвейер

1. **GenericOverlapDetector<T>** (база): `Update` → `OverlapSphereNonAlloc` (буфер 256) → событие `Detected` **каждый кадр** для каждого объекта в радиусе. Радиус масштабируется тиром игрока (`TierResolver.GetScaleFor`), подписка на `TierChanged`
2. **ItemDetector** (радиус «рта») → **Collector**: фильтр тира (`item.Tier > текущий + AmbitionTierOffset` → «не по зубам», игнор); годен → `CollectAsync`: `item.Collect()` (коллайдер off — предмет исчезает из всех детекторов) → `Absorber.AbsorbAsync` → `item.Shutdown()` → событие `ItemCollected`
3. **Absorber**: полёт по квадратичной Безье к игроку; длительность = дистанция/AbsorbSpeed, кламп [0.1; 0.45] с; дуга (перпендикуляр × дистанция × случайный ArcFraction), вращение вокруг случайной оси, сжатие с 60% пути, ease = progress^power
4. **AttractableDetector** (радиус больше рта) → **ItemAttractor**: предметы сами текут к игроку — прямое смещение transform: радиальная скорость с разгоном у «рта» (ApproachMultiplier/Power из AttractConfig) + тангенциальный свёрл (орбита, сторона по чётности instanceId × OrbitStrength)
5. **ItemGhostToggler**: предметы слишком высокого тира (тир > текущий + Ambition) вплотную к игроку (`capsuleRadius + 0.2`) становятся призраками `SetGhost(true)` — не мешают обзору, есть нельзя

## Куда уходит `Collector.ItemCollected`

[[Player]] (масса/квота) · [[LevelGenerator]] (возврат в [[ItemPool]]) · PlayerPickupSound ([[Аудио-подсистема]])

## Слабые места

- Вся цепочка исполняется **per-frame per-item**: Detected стреляет каждый кадр по каждому объекту в радиусе, фильтр тира и аттрактор — тоже (осознанно, умножается на население сцены).
- `ItemGhostToggler` без OnDisable: при выключении объекта активные призраки остаются в ghost-материале, `_ghostItems` держит устаревшие ссылки; каждый кадр квадратичный List.Contains (`ItemGhostToggler.cs:100-121`).
- `Collector.CollectAsync` при отмене (смерть сцены) не возвращает предмет в пул (`Collector.cs:84-92`) — молчаливая потеря.
- Порог «не по зубам» с перком Ambitions (+1 тир) вычисляется в двух местах независимо (Collector и ItemAttractor/ItemGhostToggler) — рассинхрон при правке одного.
