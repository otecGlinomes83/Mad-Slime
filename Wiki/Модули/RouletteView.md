# RouletteView

**Слой:** UI · **Код:** `Assets/MadSlime/Scripts/UI/Roulette/RouletteView.cs` (451 строка), `RouletteSectorCard.cs`

И встраиваемый виджет, и полноэкранный экран — один класс, два экземпляра в игре: экран ежедневного приза в Menu (Mode.Main, создан [[MadSlimeContentSetup]]: DailyRouletteScreen + CloseButton) и виджет на вкладке рулетки магазина (Mode.Skins).

## Режимы

- **Mode.Main** (ежедневный приз): лента = секторы конфига (монеты «×N» / эксклюзивные скины с цветом редкости). Спин: приоритет фри-спин → платный за монеты (100). Реклама: rewarded (`Roulette` id), лимит 3 в окне 30 мин. В Mode.Main `Update()` каждый кадр рефрешит кнопки (таймеры фри-спина/рекламы)
- **Mode.Skins** (магазин): лента = только неоткрытые скины ShopContent, отсортированные по редкости. Спин только за монеты (цена растёт: 300 + 150 × счётчик). Кнопка рекламы скрыта. **Автозапуска фри-спина при `Show()` нет** — только показ экрана, крутка по кнопке

## Выдача (OnReelStopped)

- Main: монеты → GrantCoins; выпал скин, который уже открыт → компенсация монетами; иначе GrantSkin
- Skins: все собраны → лента из **6 захардкоженных** секторов компенсации (×100); иначе GrantSkin → `BuildReel()` пересобирает ленту без выигранного скина

## Слабые места

- **Критичный баг эндгейма:** когда все скины собраны, лента строится из 6 компенсационных секторов, но `PickTargetIndex` для Mode.Skins всё равно дергает `PickSkinIndex` на **пустом пуле** → `ArgumentException`. `RefreshButtons` не проверяет `_allSkinsCollected` — кнопка активна: клик = **деньги списаны, цена крутки выросла, спин упал** (`RouletteView.cs:308-316, 423-425` + `RouletteService.cs:246-252`). Состояние постоянное. Детали: [[Техдолг и баги]].
- `OnAdSpinGranted` вызывает `RegisterAdSpin`, который может бросить `InvalidOperationException`, если окно заполнилось между кликом и колбэком рекламы (`RouletteView.cs:291-296` + `RouletteService.cs:134-138`) — упавший колбэк = проигранная реклама.
- `Show()` дергает `Initialize(Mode.Main, null)` — если один экземпляр переиспользовать в другом режиме, guard `_isInitialized` заблокирует смену (сейчас спасает только то, что в сценах два разных экземпляра).
- Магия: 6 секторов компенсации (`RouletteView.cs:214`), цвет монетного сектора `new Color(1f, 0.8f, 0.3f)` в коде (`:23`).
- `RefreshButtons()` каждый кадр в Mode.Main гоняет `PruneAdSpins` (итерация списка + `DateTimeOffset.UtcNow`) — лишняя работа и GC.
