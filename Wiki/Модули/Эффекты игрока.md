# Эффекты игрока

**Слой:** Gameplay · **Код:** `Assets/MadSlime/Scripts/Player/` (ScalePunch, MovementDeformer, SpeedSmoke)

Чисто презентационный слой: ничего не решают, только рисуют состояние.

## Состав

- **ScalePunch** — squash при поедании предмета своего тира: `DOTween.To` по SquashCurve из [[PlayerConfig]], `SetTarget`+`SetLink(KillOnDisable)`, OnDisable восстанавливает скейл. Эталон аккуратной работы с твинами в проекте
- **MovementDeformer** — рендер цикла ползка: `stretch = strength × DeformMaxStretch × CrawlStretchCurve(CrawlPhase)`, где phase/strength читаются из [[Mover]]; `localScale = (squeeze, squeeze, 1+stretch)`. В покое (strength ≈ 0) один раз возвращает базовый скейл и выходит — постоянной записи localScale нет
- **SpeedSmoke** — дым на скорости: инстанс партикла под себя (глушит emission), `Update` ставит rateOverTime = 35 при скорости ≥ SmokeSpeedThreshold (15), иначе 0, с гистерезисом `_isSmoking`

## Связи
