# Аудио-подсистема

**Слой:** Gameplay · **Код:** `Assets/MadSlime/Scripts/Audio/`

Централизованные плееры + точечные звуки-подписчики. Все источники 2D (spatialBlend 0), параметры звука — [[Мелкие конфиги Core | SfxClip]].

## Центр

- **MusicPlayer** — один loop-источник; `Play(SfxClip)`: тот же клип — no-op, другой — мгновенная замена без кроссфейда. Музыка сцен: Game, Fill, Shop ([[ShopPanel | ShopMusic]]), Menu ([[MainMenu]])
- **SfxPlayer** — пул голосов: 2 UI + 5 геймплея (round-robin, время конца = время + длина/питч); переполнение — **молчаливый дроп**; отдельный **единственный** loop-источник (`StartLoop/StopLoop`)
- **AudioMixerController** — громкость в AudioMixer (дБ = 20·log10, guard от log(0)); пишет в сейв с дебаунсом 500 мс + флеш в OnDestroy; перечитывает при `Ready`

## Точечные звуки

| Звук | Триггер | Особенность |
|---|---|---|
| PlayerPickupSound | `Collector.ItemCollected` | случайный интервал 0.05–0.1 с + случайный питч |
| TierUpSound | `PlayerTier.TierChanged` | только при реальном повышении |
| TimerTickSound | `Timer.Ticked` | луп на последних 20 с, стоп на 0/Finished |
| FlyingCubeArrivalSound | `ShapeFiller.CubeArrived` | питч растёт с заполнением (0.9→1.35), троттлинг 0.03 с |
| UIButtonSound | `onClick` | авто-инжект скоупами ([[Скоупы сцен]]), клип вешает дизайнер |
| AudioSettingsPanel | слайдеры | тик SFX-слайдера с троттлингом 0.08 с (unscaled) |

## Связи

- [[Timer]], [[PlayerTier]], [[Детекция и сбор | Collector]], [[Заливка фигуры | ShapeFiller]], кнопки всего UI, [[PlayerProgress]] (громкости)

## Слабые места

- **Один loop-источник** на SfxPlayer: TimerTickSound — единственный лупер сейчас, второй конкурент заглушит первый (`SfxPlayer.cs:146-149`, `TimerTickSound.cs:70`).
- Дебаунс-сейв громкости на **масштабируемом** Delay: под паузой (настройки открыты из паузы) персистится только после анпауза (`AudioMixerController.cs:128-143`).
- Переполнение голосового пула молча дропает звук — без вытеснения старого.
