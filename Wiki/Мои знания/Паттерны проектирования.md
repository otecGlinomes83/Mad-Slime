## Factory Method
Порождающий паттерн, определяет общий метод создания объекта, но позволяет наследникам решать, какой конкретный объект создавать.
### Что решает:
Убирает прямое создание конкретных объектов из основной логики
Заместо:
`var enemy = Instantiate...`
Это:
`var enemy = CreateEnemy();`
### Когда нужен:
Существуют разные типы создаваемых объектов;
Способ создания зависит от конкретного класса;
Объект после создание требуется донастроить;
Основной код не должен знать про конкретный класс или префаб;

### Пример:
```
public abstract class EnemySpawner : MonoBehaviour
{
    public Enemy Spawn()
    {
        Enemy enemy = CreateEnemy();
        enemy.Initialize();
        return enemy;
    }

    protected abstract Enemy CreateEnemy();
}
```
### Конкретная реализация:
```
public class GoblinSpawner : EnemySpawner
{
    [SerializeField] private Goblin prefab;

    protected override Enemy CreateEnemy()
    {
        return Instantiate(prefab);
    }
}
```

### Главный недостаток
Для каждого нового варианта создания нужно создавать новую фабрику.
