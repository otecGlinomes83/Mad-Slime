# Responsive UI

Система портретной и горизонтальной раскладки uGUI.

## Порядок чтения

1. `Runtime/ResponsiveCanvasLayout.cs` — данные двух профилей: цели, якоря, pivot, положение, размер и масштаб. Во время игры выбирает профиль по Screen.width/height при включении и изменении разрешения. Данные хранятся в компонентах сцен и префабов.
2. `Editor/ResponsiveCanvasLayoutEditor.cs` — инспектор: источник размера области, вариант рулетки, кнопки записи текущей геометрии в Portrait/Landscape.
3. `Editor/PrefabLayoutPreview.cs` — область редактирования в Prefab Mode, отслеживание Game View, применение профилей, временные настройки Canvas и их восстановление при сохранении/закрытии.

## Дополнительные компоненты

- `Runtime/RoulettePopupLayout.cs` — выбор профилей рулетки с кнопками и без кнопок; центрирование единственной доступной кнопки.
- `Runtime/ResponsiveSkinGrid.cs` — подбор числа колонок и размера ячеек магазина по ширине контейнера.
- `Runtime/MadSlime.UI.asmref` — сохраняет принадлежность runtime-кода сборке MadSlime.UI. Папка Editor остаётся в редакторской сборке Assembly-CSharp-Editor.

## Настройка

Открой префаб. По умолчанию область в Scene следует разрешению Game View; фиксированный формат выбирается через «Размер области». Настрой Rect Transform, нажми «Записать в Portrait/Landscape» и сохрани префаб. Перед сменой ориентации запиши ручные правки. Шрифты, спрайты и цвета не входят в снимок геометрии.

Окна, использующие систему, остаются в своих папках. Например, PauseMenu.Initialize проверяет ResponsiveCanvasLayout.Manages перед изменением позиции языка. Сами профили и ссылки на элементы находятся в сценах и префабах, а не в отдельных файлах этой папки.

При переносе сохранены исходные .meta и GUID скриптов, имена классов и принадлежность сборкам. Логика не изменена.
