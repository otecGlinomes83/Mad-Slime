# Заливка фигуры

**Слой:** Gameplay · **Код:** `Assets/MadSlime/Scripts/ShapeFill/` (GridBuilder, ShapeFiller, CubeSpawner, FlyingCube, FillTapInput, FillFinale, FillDebug)

Наградная мини-игра Fill: фигура уровня заливается кубиками, тапы ускоряют.

## GridBuilder — растр → сетка

Читает пиксели текстуры формы (шаг = ceil(w/64)), ячейка заполнена при alpha > 0.1 (хранит цвет); классификация бордюра: край сетки / пустой прямой сосед / пустой на расстоянии 2 (утолщение контура); FillCells сортируются **снизу вверх, слева направо** — заливка «наливается». Текстуру подменяет тема уровня ([[FillSessionHandler]] → `SetShapeTexture`).

## ShapeFiller — движок

- Стадии буста: Normal (спавн 0.04 с, полёт 0.5 с) → **первый тап** → Boosted (0.015/0.25) → **второй тап** → Instant: остаток разлетается порциями за InstantFillDuration 0.25 с (полёт 0.1 с)
- Между квотной и бонусной волной — пауза BonusWave; бонусные кубы с тинтом
- Призрак фигуры: `Sprite.Create` из текстуры, alpha 0.4; бордюр — каскадный спавн (длительность/число кубов, округление до мс — может выродиться в мгновенный)
- `CanRescue` = результат есть, не льёмся, недолив > 0 → `Rescue()` доукомплектовывает target до полного
- Завершение: `FillCompleted(arrived / required)` — < 1 при недоливе (провал), 1 при полном
- Задержки **масштабируемые**: под рекламной паузой заливка замирает (для этой сцены — ок, но не документировано)

## Кубы и финал

- **CubeSpawner**: `Instantiate` на каждый куб (без пула), цвет через MaterialPropertyBlock; **FlyingCube**: полёт по Безье, stretch по синусу пути, качение вокруг forward с доводкой, squash при посадке, событие `Arrived`; GrowIn для бордюра
- **FillTapInput**: `IPointerDownHandler` → `Accelerate()` (только при timeScale > 0)
- **FillFinale** (100%): конфетти — эмит по одной частице с цветом случайной заполненной ячейки (бёрсты партикла вырезает в Awake и эмитит вручную); DOPunchScale грида; FOV-кик камеры — **твин привязан `SetLink` к себе, а не к камере** (`FillFinale.cs:146-153`)
- **FillDebug**: ContextMenu-тесты; в `Awake` при пустой квоте **молча выключает продовый FillSessionHandler** (`FillDebug.cs:81-84`) — компонент зарегистрирован в проде ([[Скоупы сцен | FillLifetimeScope]])

## Слабые места

- Кубы не пулятся: сотни `Instantiate` + `GetComponent<Renderer>` за секунды на пике — главный перф-долг WebGL-сцены (`CubeSpawner.cs:33-52`).
- Камерный твин FillFinale переживёт смерть камеры (не тот owner у SetLink).
- Каскад бордюра: `perCubeDelay` округляется до целых мс — при большом бордюре станет 0 и каскад исчезнет (`ShapeFiller.cs:260-281`).
- FillDebug в прод-цепочке DI — мягкий софтлок вместо fail-fast при пустой квоте.
