# Камера

**Слой:** Gameplay · **Код:** `Assets/MadSlime/Scripts/Camera/` (CameraFollow, CameraImpulse)

«Хаптика» камеры: слежение + импульсы от поедания и тир-апов.

## CameraFollow

- `LateUpdate`: позиция = target + оффсет (масштаб оффсета по тиру — камера отъезжает с ростом) с SmoothDamp (max speed 50) + Perlin-шейк по `Impulse.Shake`; `fieldOfView = baseFov + Impulse.FovKick` каждый кадр
- «Подтяжка»: при `Impulse.Pull` длина оффсета ужимается — камера присаживается ближе к слайму при жоре

## CameraImpulse — источник импульсов

- `ItemCollected(definition)`: `pull += MassToPullStrength.Evaluate(mass)` (кривая из CameraImpulseConfig, cap 6); масса ≥ 1000 → `shake += 0.15` (cap 0.35)
- `TierChanged` (только вверх): пуш назад (`pull −= 4`, до −8) + FOV-кик 7°
- `Update`: экспоненциальное затухание всех трёх каналов

## Связи

- [[PlayerTier]], [[LevelProgress]] (ItemCollected), [[TierTable]] (масса), CameraImpulseConfig ([[Мелкие конфиги Core]]), [[Заливка фигуры | FillFinale]] (свой FOV-кик на 100%)

## Слабые места

- Двойная точка подписки OnEnable+Start с флагом (`CameraImpulse.cs:52-60`) — работает, но дублирует логику.
- FOV пишется каждый кадр без сравнения — микро-оверхед.
- FillFinale твинит FOV камеры, привязывая твин к своему объекту — см. [[Заливка фигуры]].
