# Конфиги уровней

**Слой:** Core · **Код:** `Assets/MadSlime/Scripts/Core/Scriptables/Levels/`

Пакет ScriptableObject'ов, полностью описывающих контент уровня: что лежит на полу, где, в каких тирах, с какой квотой и на какое время.

## Зачем

Весь контент уровней — данные, не код: новые уровни = новые ассеты, редактор (`Mad Slime/Setup Content`) умеет их генерировать.

## Состав

- **LevelConfig** (`Mad Slime/Level Config`) — корневой конфиг уровня:
  - `_theme`: LevelTheme — материал пола + текстура формы для сцены заливки (альфа = силуэт)
  - `_propSet`: PropSet — список пропов `List<Item>` + варианты `PropVariant` (тот же префаб с другим `ItemDefinition` — другая иконка/тир)
  - `_minTier`/`_maxTier` — диапазон тиров спавна (клампятся в геттерах, максимум Boss)
  - `_timerDuration` (по умолчанию 90 с)
  - генерация квоты: `_quotaTypesMin/Max` (1–3 типа), `_quotaTargetMin/Max` (3–8 штук), `_quotaMaxSameTier` (2 — лимит типов квоты на один тир)
- **LevelsCatalog** (`Mad Slime/Levels Catalog`) — `List<LevelRange>`: «с уровня X по Y → такой LevelConfig»
- **LayoutsLibrary** — `List<LayoutSet>`, при генерации выбирается один
- **LayoutSet** — зоны спавна: `SpawnZone` (форма Grid/Circle/Scatter/CircleGrid, центр, радиус, count, тир-диапазон), `_allowMirroring`, авторасстояние (шаг = радиус крупнейшего предмета × 2.2, мин. дистанция = шаг × 0.7)
- **LevelTheme** — `_floorMaterial` + `_fillShapeTexture` (цвета текстуры проступают в призраке и конфетти)

## Связи

- **Выбирается:** [[LevelConfigResolver]] (по номеру уровня через LevelsCatalog)
- **Потребляется:** [[LevelGenerator]] (раскладка через ZoneLayoutPlanner), [[QuotaGenerator]] (параметры квоты), [[FillSessionHandler]] / заливка (текстура формы)

## Слабые места

- Целостность ассета не валидируется: клампы только в геттерах `LevelConfig.cs:43-50`, `_quotaMaxSameTier` не сверяется с `_quotaTypesMax` — кривой ассет вскроется только в рантайме генерации.
- `PropSet._props` хранит `List<Item>` — ссылки на компоненты префабов: конфиг тянет за собой MonoBehaviour с DOTween-логикой вместо чистых данных.
